# Random-Linear-Gradient-Generator
# 🎨 Random Linear Gradient Generator

A simple and interactive web application that generates random linear gradients using HTML, CSS, and JavaScript.

## 🚀 Live Demo

**[Click here to view the live website](https://chandanreddy2005.github.io/Random-Linear-Gradient-Generator/)**

## ✨ Features

- 🎨 Generate random hexadecimal colors.
- 🌈 Create beautiful linear gradients dynamically.
- 🖱️ Change gradient colors using interactive buttons.
- 📋 Copy the CSS gradient code to the clipboard.
- 📱 Simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## 💻 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/chandanreddy2005/Random-Linear-Gradient-Generator.git
   ```

2. Open the project folder.
3. Open `gradient.html` in your browser.

   If you rename the file to `index.html`, open `index.html` instead.
